# Jump n Gun
 
Created by Franklin Dai, Nat Hill, Yimo Wang, and David Su
 
A network-based multiplayer 2D platformer built around explosive propulsion — blast your teammates to new heights, or send your rivals plummeting back down. All modes require an online connection; local co-op is not supported.
 
---
 
## Gameplay
 
### Co-op Mode (2–4 Players)
 
Work together to ascend puzzle-driven levels using explosive weapons to launch each other upward. Inspired by the rocket jump mechanic from TF2, Jump n Gun translates that verticality into a 2D co-op context where teamwork — and well-timed explosions — are the only way to progress.
 
- **2 to 4 players** collaborate through hand-crafted levels
- Puzzles are designed around the boost mechanic — some ledges simply can't be reached alone
- Coordinate launches, chain boosts, and time your shots to clear obstacles together

### Party Mode (2–8 Players)
 
Race to the top of a vertical level — but nothing says you have to play nice. Blast opponents back down with your explosive weapons and claw your way to first place.
 
- **2 to 8 players** compete in a chaotic vertical race
- Use the same explosive mechanics to hinder rivals and boost yourself
- Fast, replayable rounds designed for group fun

## Running the Game
 
### Prerequisites
 
- [Godot Engine 4.x](https://godotengine.org/download) — download the standard version for your platform
### Steps
 
1. **Clone the repository**
   ```bash
   git clone https://github.com/your-org/jump-n-gun.git
   cd jump-n-gun
   ```
 
2. **Open the project in Godot**
   - Launch the Godot editor
   - Click **Import** in the Project Manager
   - Navigate to the cloned repository folder and select `project.godot`
   - Click **Import & Edit**
3. **Run the game**
   - Press **F5** (or click the ▶ Play button in the top-right) to launch from the main scene
   - Alternatively, open any scene file and press **F6** to run that scene directly
### Exporting a Build (Optional)
 
1. Go to **Project → Export**
2. Add an export preset for your target platform (Windows, macOS, Linux)
3. Click **Export Project** and choose an output directory
> Make sure you have the appropriate export templates installed via **Editor → Manage Export Templates**.
